## 📄 목적
본 프레임워크는 단순한 기능 나열을 넘어, 경쟁사가 어떤 **'가치(Value)'**를 **'어떤 가격 구조(Price)'**로 판매하는지, 그리고 이 가치가 시장에서 어느 정도의 **'지불 의사(Willingness to Pay)'**를 갖는지 수치적으로 분석하여, AI office의 최적 포지셔닝과 수익 모델을 도출하는 데 사용합니다.

## 💡 핵심 분석 차원 (Dimension)
1.  **핵심 기능 (Feature):** 경쟁사가 제공하는 구체적인 기능 (예: 실시간 주가 알림, 특정 섹터 백테스팅, AI 기반 포트폴리오 최적화 등).
2.  **고객 가치 (Value Proposition):** 해당 기능이 고객의 어떤 문제를 해결하는지 (Pain Point 해결).
3.  **가격 구조 (Pricing Model):** 구독료, 건당 과금, 무료제공 여부 등.
4.  **수익화 포인트 (Monetization Angle):** 이 기능이 결국 회사의 매출로 연결되는 핵심 지점.

## 📝 분석 항목별 세부 체크리스트

| 분석 항목 | 세부 내용 | 데이터 수집 출처 | 분석 관점 (Question) |
| :--- | :--- | :--- | :--- |
| **A. 핵심 서비스 정의** | 주요 타겟 시장, 핵심 메시지 | 공식 웹사이트, 마케팅 자료 | "이 서비스가 가장 강조하는 '단 하나의 가치'는 무엇인가?" |
| **B. 가격 모델 분석** | 가격 등급, 각 등급별 제공 기능 | Pricing Page | "가장 낮은 가격대에서 무엇을 포기하도록 유도하는가?" |
| **C. 기능 심층 분석 (Deep Dive)** | 1. 필수 기능 (Must-Have) / 2. 차별화 기능 (Differentiator) | 사용 후기, API 문서 | "이 기능이 없으면 고객이 겪을 최대의 손실(Loss)은 무엇인가?" |
| **D. 시장 포지셔닝** | 경쟁 우위 주장, 시장 내 이미지 | 언론 보도, 전문가 리뷰 | "경쟁사는 스스로를 '무엇'으로 정의하고 있는가?" |

## 📈 포지셔닝 맵 활용 (Positioning Map)
*   **X축:** (예: 기술 복잡성) 낮음 $\leftrightarrow$ 높음
*   **Y축:** (예: 사용자 접근성) 낮음 $\leftrightarrow$ 높음
*   **활용:** 경쟁사들이 어느 영역에 몰려 있는지, 그리고 AI office가 진입할 수 있는 '미개척 영역(Blue Ocean)'은 어디인지 시각화합니다.

### 🛠️ 3. 초기 경쟁사 분석 대상 및 분석 실행 (가상의 초기 분석)

현재 시장에서 AI 투자 리포트/시스템을 제공하는 핵심 경쟁사 3곳을 가정하고, 해당 프레임워크에 따라 초기 분석 틀을 채워 넣습니다.

**[가정된 경쟁사]**
1.  **Competitor A:** 대형 증권사 연동 분석 툴 (높은 신뢰도, 복잡한 기능)
2.  **Competitor B:** 개인 투자자용 간편 트렌드 분석 앱 (사용자 친화적, 낮은 진입장벽)
3.  **Competitor C:** 전문 기관용 리서치 플랫폼 (매우 깊은 데이터, 고가)

**[초기 분석 요약]**

| 분석 항목 | Competitor A (대형 증권사) | Competitor B (간편 앱) | Competitor C (기관 플랫폼) | AI office의 기회 (Gap) |
| :--- | :--- | :--- | :--- | :--- |
| **핵심 가치** | 신뢰성, 규제 준수 (Trust) | 접근성, 편의성 (Ease) | 깊이, 전문성 (Depth) | **'접근 가능한 깊이'** - 전문가 수준의 분석을, 개인 투자자가 쉽게 이해하도록 제공. |
| **가격 구조** | 높은 초기 수수료 + 구독료 | 무료/저가 광고 기반 | 매우 높은 연간 구독료 | **'단계별 가치 부여'** - 무료/저가로 유입시킨 후, 고가 기능(백테스팅)을 유료화. |
| **주요 Gap** | UI/UX가 복잡하고, 일반 투자자에게 어렵게 느껴짐. | 데이터의 신뢰성이나 깊이가 부족함. | 너무 복잡하고, 개인 투자자에게는 과도한 비용 부담. | |
